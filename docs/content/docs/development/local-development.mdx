# Local Development

The main application lives in `web/`. The browser sends AI requests directly to the user's OpenAI-compatible endpoint.

## Start the frontend

```bash
cd web
bun install
bun run dev
```

Open `http://localhost:3000`, then enter your `Base URL`, `API Key`, and model names in Settings. Prompt sources and WebDAV are also accessed directly by the browser.

## Start the documentation site

```bash
cd docs
bun run dev
```

## Package the desktop app

See [desktop/README.md](https://github.com/hyc0122/jiasu-canvas/blob/main/desktop/README.md) for the Electron wrapper. `cd desktop && npm run pack` builds `web/` with `VITE_BASE=./` then packages installers into `release/`. The default `bun run build` in `web/` is unchanged and still uses `base: '/'`.

Common locations:

- Canvas, pages, and interactions: `web/`
- Prompt caching: `web/src/services/api/prompts.ts`
- Documentation content: `docs/content/docs/`
- Desktop packaging: `desktop/`
